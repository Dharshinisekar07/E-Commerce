##  About the Project

**Cara** is a modern, fully responsive e-commerce fashion website designed to showcase front-end development skills. It features a complete shopping experience — from browsing products and reading blogs to adding items to the cart, applying coupon codes, filling shipping details, and selecting payment methods.

This project was built as a portfolio project to demonstrate proficiency in **HTML5**, **CSS3**, **JavaScript**, **responsive design**, and **multi-page web architecture**.



##  Features

###  Home Page
-  **Hero Banner** — Trade-in offer with "Shop Now" CTA
-  **Feature Icons** — Free Shipping, Online Order, Save Money, Promotions, Happy Sell, 24/7 Support
-  **Featured Products** — Summer collection grid with star ratings and Add to Cart button
-  **Promo Banner** — Up to 70% off on t-shirts & accessories
-  **New Arrivals** — Latest summer collection display
-  **Category Banners** — Buy 1 Get 1 Free, Upcoming Season, Seasonal Sale, Footwear, T-Shirts
-  **Newsletter Signup** — Email subscription section
-  **Footer** — Contact info, About links, My Account links, App Store / Google Play badges, Payment gateways (VISA, Mastercard, Maestro, Amex)

###  Shop Page
- Full product catalog with pagination (Page 1 & 2)
- Product cards with brand, name, star rating, price, and Add to Cart button
- #stayhome banner

###  Cart & Checkout
- **Cart Page** — Item list with quantity +/− controls, size & color info, order summary
- **Coupon Code** — Apply discount (e.g. CARA20)
- **Shipping Details Form** — Name, email, address, city, zip, state, country, phone
- **Payment Method** — Card, PayPal, Apple Pay, COD options
- **Order Summary** — Live subtotal, free shipping, discount, tax (8%), and total calculation
- **3-Step Checkout Progress** — Cart → Checkout → Confirmation

###  Blog Page
- Full-width hero banner with #readmore tagline
- Blog post listings with date, image, title, and excerpt
- Posts: Cotton-Jersey Hoodies, How to Style a Quiff, Must-Have Skater Girl Items, Runway-Inspired Trends, AW20 Menswear Trends
- Pagination support

###  About Page
- KnowUs hero section
- Who We Are section with illustration
- Download Our App section with mobile app mockup
- Feature highlights with icons

###  Contact Page
- let's_talk hero banner
- Google Maps embed (Chennai, Tamil Nadu)
- Contact form — Name, Email, Subject, Message, Submit
- Team contact cards — John Doe, William Smith, Emma Stone

##  Getting Started

No installation needed — this is a pure HTML/CSS/JS project.


1. Clone the repository
git clone https://github.com/your-username/cara-ecommerce.git

2. Navigate to the project folder
cd cara-ecommerce

3. Open in browser
open index.html
OR just double-click index.html in your file explorer


To run with a local server (recommended):


## Using VS Code Live Server extension
## Right-click index.html → Open with Live Server

## OR using Python
python -m http.server 5500
## Open http://localhost:5500
